# Farhad Trainer V2

V2 fixes the V1 persistence problem by storing workouts and drafts in IndexedDB.

## Highlights
- Reliable draft persistence across tabs/reloads
- Completed workout history
- Expandable workout cards
- Previous / suggested / coach progression view
- Rest timer per exercise
- Learn tab with form cues, muscles worked, substitutions, and YouTube demo searches
- Body progress and training-volume charts
- Weekly check-in and coaching summary
- Tuesday / Thursday / Saturday calendar export
- Offline-capable installable PWA

## Update your GitHub repository
Replace the existing files in the repository root with the files in this package.
GitHub Pages will redeploy automatically from `main` / `(root)`.
