# Farhad Trainer

Personal 12-week body recomposition PWA.

## Features
- Tuesday / Thursday / Saturday workout schedule
- 3-day home gym + dumbbell training plan
- Exercise muscle groups and substitutions
- Set-by-set weight, reps, RPE, completion logging
- Rest timer
- Automatic next-session progression suggestions
- PR tracking
- Body weight and measurement tracking
- Progress charts
- Weekly check-ins with automatic coaching summary
- 12-week calendar export
- Offline-capable PWA
- Add to Home Screen support
- Local data export

## GitHub Pages
After uploading these files to the repository, enable GitHub Pages from:
Settings → Pages → Deploy from a branch → main / root
